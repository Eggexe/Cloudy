# Changelog

## Vers. 1.0.0 - 2026 - 04 - 30

### Added:
- Window creation & destruction (CDY_SimpleWindowCreate, CDY_SimpleWindowDestroy)
- Renderer abstraction (CDY_DrawEntity, CDY_ColorRenderer, CDY_WipeRenderer, CDY_ArmRenderer)
- Input manager with CDY_Scancode abstraction
- Entity system
- Entity translation & AABB collision
- FPS management & tracking
- UI text rendering with Press Start 2P
- Event system with CDY_Event

## Vers. 1.1.0 - 2026 - 05 - 12
- Clears old file structure for a cleaner look
- /include features public include directories
- /src features engine internals
- /assets features nice assets that come for free (lucky us)
- /tests features tests for the engine so I can ensure what I write is working
